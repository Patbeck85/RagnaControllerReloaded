# Views/Windows — Main Application Windows

Primary application windows for the main UI, settings, and splash screen.

## Files

| File | Responsibility |
|------|----------------|
| `MainWindow.xaml` / `.cs` | Main UI, status display, tab navigation |
| `SettingsWindow.xaml` / `.cs` | General settings (sound, rumble, window mode, language) |
| `SplashWindow.xaml` / `.cs` | Animated startup splash screen |

## Namespace

`RagnaController.Views.Windows`
