# Controls — Reusable UI Controls

Shared WPF controls used across multiple windows.

## Files

| File | Responsibility |
|------|----------------|
| *(various)* | Themed controls (DarkComboBox, etc.) following the Obsidian & Gold design system |

## Notes

- All controls use the Obsidian & Gold glassmorphism theme
- Controls are reused across Views/Windows, Views/Dialogs, Views/Overlays, and Views/Editors
