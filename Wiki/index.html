🚀 Getting Started

  1. 1. Install .NET 8 Runtime

    RagnaController requires .NET 8 Desktop Runtime for Windows. Download from dotnet.microsoft.com.

  2. 2. Launch the Application

    Run RagnaController.exe from the release package or build from source:

    dotnet run --project src/RagnaController/RagnaController.csproj

  3. 3. Select Ragnarok Online Executable

    Navigate to Settings → Ragnarok Online .EXE Path and select your ragexe. This is required for the overlay to hook into the game.

  4. 4. Configure Your Controller

    Go to Settings → Select your connected gamepad/controller. The app will read button mappings and initialize the engine.

  5. 5. Create or Load a Profile

    Use the Profile Wizard (first run) or Profile Library to create a new class-specific profile. The wizard auto-detects your class from button mappings.

  6. 6. Start the Engine

    Click "Start Engine" in the main window. The overlay will appear in Ragnarok Online.

🎯 Core Features

🤖 Auto-Class Detection

How It Works

The system automatically detects your RO class from your controller button mappings. When you advance from Step 2 → 3 in the Profile Wizard, the system:

  • Scans all active button mappings from your profile
  • Matches detected skills against the SkillToClassMap weighted dictionary
  • Uses weighted heuristic scoring:
  • Weight 3: Signature skills unique to a class (e.g., Spiral Pierce for Lord Knight, Storm Gust for High Wizard)
  • Weight 2: Class-specific skills shared within a category
  • Weight 1: General category skills

The class with the highest weighted score is selected and persisted in your profile.

📋 Profile Wizard

Step-by-Step Workflow

The Profile Wizard guides you through profile creation in 5 steps:

  1. Step 1: Profile Name

    Enter a profile name. The system validates the name contains only letters, numbers, and spaces.

  2. Step 2: Button Mapping

    Remap your controller buttons. The system shows which buttons are already mapped and allows you to assign actions to A, B, X, Y, LB, RB, L3, R3, D-Pad directions.

  3. Step 3: Auto-Class Detection

    This is where auto-detect runs. The system analyzes your button mappings and suggests a class. You can accept the suggestion or manually select from the class dropdown (Lord Knight, High Wizard, Sniper, Clown, Gypsy, Assassin Cross, Whitesmith, Creator, High Priest, Champion, Super Novice, Melee).

    Detection uses weighted scoring: Signature skills = weight 3, Class-specific = weight 2, General = weight 1.

  4. Step 4: Combat Engine Configuration

    Enable/disable combat engines: Auto-Target, Kite Engine, Mage System, Support Mode. Configure quick keys for each engine.

  5. Step 5: Finish & Save

    Review profile summary, click "Finish" to save. The profile is persisted with all settings, class detection result, and engine configurations.

Wizard Navigation

  • Btn_Back: Go back to previous step
  • Btn_Next: Proceed to next step
  • Btn_Finish: Complete profile creation and save

⚔ Combat Engines

Auto-Target Engine

Automatically targets the nearest enemy mob or player. Features:

  • Range limit: Configurable (default 12m)
  • Leash detection: Disengages when target moves beyond range
  • Priority: Nearest HP % lowest first
  • Toggle: Enable/Disable via quick key

Kite Engine

Automatically retreats while shooting — ideal for ranger/mage kiting. Features:

  • Activates when enemy closes distance
  • Retreat direction: Away from target based on angle estimation
  • Auto-resumes shooting when distance is safe
  • Configurable retreat speed threshold

Mage System

Advanced mage/caster support with ground spell integration. Features:

  • Ground spell support: Stone Curse, Frozen Ground, Healing Circle AOEs
  • Cast bar protection: Doesn't move/interrupt when casting > 1.5s unless stunned
  • Mana management: Auto-potion when < 30% (configurable threshold)
  • Skill queue: Casts next skill when GCD available

Support Mode

Healer/support class optimization. Features:

  • Party member targeting: Auto-detects nearest party member HP < 70%
  • Heal priority: Single target → party → self, with cooldown per target
  • Resurrection: Auto-casts Revive/Resurrection when party member downed
  • Debuff clear: Auto-dispels Stone Curse/Poison on party

🌑 Ground Spells (AoE)

Supported Ground Spells

  • Stone Curse: AoE curse that reduces enemy defense — radius configurable, duration 30s
  • Frozen Ground: Slows enemies within radius — ideal for kiting, duration 20s
  • Healing Circle: Heals party members within radius over time — ticks every 3s
  • Fire Wall: Damage-over-time AoE — damage scales with ASPD
  • Telepado: Teleportation circle — tp location configurable

How Ground Spells Work

  1. Select ground spell from Profile Wizard → Combat Engines
  2. Configure radius, duration, tick interval, and whether it follows target or is self-cast
  3. Engine registers the spell when you fire your first skill (connected to CombatEngine.ActionFired)
  4. Ground spell enters ActiveGroundSpell tracking with duration management
  5. Every tick: engine updates duration, checks radius, applies effects to entities within range
  6. Auto-cleanup: Spell automatically removes when duration reaches 0

Configuration Properties

// GroundSpell properties (configure in Profile Wizard Step 4)
{
  "DurationSec": 30,       // Total spell duration
  "TickIntervalMs": 3000,  // How often effects are applied
  "Radius": 5.0,          // AoE radius in meters
  "FollowsTarget": false, // Whether spell tracks the target
  "IsHealing": false,     // Whether this is a healing spell
  "IsSelfCast": false     // Whether spell is self-targeted
}

❓ Frequently Asked Questions

Q: The auto-class detection doesn't recognize my class.

A: The system uses weighted heuristic scoring. If your class isn't recognized:

  1. Manual select from the ClassCombo in the Profile Wizard
  2. Ensure your button mappings are correctly set in the wizard Step 2
  3. Check that you're using skill names as they appear in the game (EUC-KR encoding for RO sprites)
  4. Supported transcendent classes: Lord Knight, High Wizard, Sniper, Clown, Gypsy, Assassin Cross, Whitesmith, Creator, High Priest, Champion, Super Novice
Q: How do I add a new language to the locales?

A: Copy en.json, translate all string values (keep keys exactly as they are), place in Locales/. The language will appear in the selector automatically. 41 languages already included.

Q: The overlay isn't appearing in game.

A:

  1. Verify you've selected the Ragnarok Online .EXE path in Settings
  2. Run the game as Administrator (or disable Admin warning)
  3. Ensure the engine is started (click "Start Engine" in main window)
  4. Check that your controller is connected and configured
  5. If using Interception driver: Ensure it's installed and the bypass is active
Q: Can I use RagnaController without a controller?

A: Yes — keyboard emulation is available. Some features (adaptive triggers, haptic feedback) require a gamepad. The system gracefully degrades if no controller is detected.

Q: How do I reset all settings to defaults?

A: Click "RESET TO DEFAULT" in the settings window, or delete your profile file from the Profiles folder. All custom configurations will be restored to factory defaults.
