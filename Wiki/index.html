From Source

Build from source using .NET 8:

cd RagnaController
dotnet build
dotnet run

🏠 Introduction

RagnaController v2.0.0 is the result of a fully autonomous development cycle. From analysis to release, every phase was executed by AI agents per SOUL.md governance. This wiki documents everything you need to know.

🚀 Getting Started

  1. Install .NET 8 SDK
  2. Download or build RagnaController
  3. Launch the application
  4. Select your RO .EXE
  5. Choose or create a profile
  6. Start the engine

📖 How It Works

The system uses a multi-agent autonomous framework following SOUL.md v2.0 Enterprise principles. Key components:

  • ClassDetector: Weighted skill-to-class mapping with signature prioritization
  • ProfileWizard: Step-by-step setup with auto-detection
  • EngineOrchestrator: Core engine managing all combat systems
  • Localization: 41 language locales for global usage

⚙️ Configuration

All settings are profile-based and persist between sessions. Configure:

  • Auto-attack and kite behavior
  • Mage spell targeting and casting
  • Support and mobsweep settings
  • Controller button remapping
  • Deadzone and curve adjustments

🔧 Troubleshooting

Common issues and solutions:

  • Class not detecting? Check skill mappings in ClassDetector.cs
  • Overlay not showing? Verify admin rights and DirectX hooks
  • Tests failing? Run dotnet test --no-restore
  • Release artifacts clean? Verify release_final/ isolation
